# 사무실 에셋 교체 가이드

사무실 그래픽은 기본적으로 코드로 그린 임시 도트입니다. 이 폴더에 PNG를 넣고
`manifest.json`의 `sprites`에 등록하면 해당 요소만 이미지로 바뀝니다. 등록하지 않은
요소는 계속 기본 도트로 그려집니다. 브라우저를 새로고침하면 바로 반영됩니다.

## 좌표계

- 월드 해상도는 536×340 논리 픽셀(바닥 18×15칸)이고, 화면에는 2배 이상이면 정수배로 확대됩니다(픽셀이 뭉개지지 않음).
- 바닥 타일은 32×16 아이소메트릭 마름모입니다.
- 모든 스프라이트는 `anchor` 지점이 "바닥에 닿는 점"에 오도록 그려집니다.
  기본값은 프레임의 가운데 아래 `[frameW/2, frameH]`입니다.

## 등록 가능한 키

| 키 | 그려지는 위치(anchor 기준) |
| --- | --- |
| `floor` | 각 바닥 타일의 아래 꼭짓점 |
| `desk` | 책상 바닥면 중심 |
| `table` | 회의 테이블 바닥면 중심 |
| `plant` | 화분 바닥 중심 |
| `cooler` | 정수기 바닥 중심 |
| `chair` | 사무용 의자 앉는 자리 바닥 중심(등받이 포함 한 장) |
| `bookshelf` | 대표실·기획실 책장 바닥 중심 |
| `sofa`, `loungeTable`, `coffee` | 라운지 소파·탁자·커피 머신 바닥 중심 |
| `rack` | 서버실 랙 바닥 중심(`work`: 명령 실행 중, `idle`: 대기) |
| `console` | 서버실 확인 결과 모니터 바닥 중심 |
| `cabinet`, `shredder` | 문서 보관실 캐비닛·파쇄기 바닥 중심 |
| `board` | QA실 체크리스트 칠판 바닥 중심 |
| `stageBoard` | 회의실 업무 단계 보드 바닥 중심 |
| `char.ceo`, `char.planner`, `char.dev`, `char.qa` | 직원 발 위치 |
| `char.sec`, `char.member`, `char.temp` | 비서, 개발 팀원, 임시 도우미(팀원이 모두 바쁠 때) 발 위치 |
| `char.<이름>.seated` | 모니터를 보고 앉은 뒷모습(예: `char.dev.seated`). 없으면 기본 도트로 그림 |
| `char.<이름>.seatedFront` | 앞을 보고 앉은 모습(대표·기획자). 다리는 책상에 가려짐 |

## 직원 스프라이트 애니메이션

직원 스프라이트는 프레임을 이어 붙인 스프라이트 시트를 씁니다(여러 줄도 가능).
상태별로 아래 애니메이션 이름을 찾고, 없으면 `idle`을 씁니다.

- `idle`: 대기
- `think`: 생각 중(응답 생성 전)
- `work`: 도구 사용/코드 작성 중
- `wait`: 사용자 승인 대기
- `walk`: 이동 중(자리·회의실 사이)

## 예시

```json
{
  "sprites": {
    "char.dev": {
      "src": "dev.png",
      "frameW": 16,
      "frameH": 28,
      "anchor": [8, 27],
      "fps": 6,
      "anims": { "idle": [0, 1], "think": [0, 1], "work": [2, 3], "wait": [4], "walk": [5, 6, 7, 6] }
    },
    "desk": { "src": "desk.png", "anchor": [16, 18] },
    "floor": { "src": "floor.png", "anchor": [16, 16] }
  }
}
```

말풍선과 이름표는 가독성을 위해 화면 해상도에서 도트 폰트(Galmuri)로 따로 그립니다.
